# Memory Allocator Simulator

An interactive web-based simulator for understanding memory allocation strategies in Operating Systems.

## Features

- **Allocation Algorithms:** Explore First Fit, Best Fit, Worst Fit, and Next Fit.
- **Fragmentation Dashboard:** Understand memory fragmentation through visual representations.
- **Request Queue:** Simulate memory allocation requests.
- **Algorithm Comparison:** Compare the behavior and trade-offs of different allocation strategies.
- **Custom Queue Builder:** Experiment with custom memory allocation scenarios.

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Getting Started

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm.

### Installation

Clone this repository:

```bash
git clone https://github.com/Raviyadav0726/Memory_allocator.git
cd Memory_allocator
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal.

## Production Build

```bash
npm run build
```

The production files will be generated in the `dist` folder.

## Project Purpose

This project demonstrates how different memory allocation strategies work and helps learners compare their behavior through an interactive interface.
